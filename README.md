A tiny deterministic program that writes one status update — the line an AI agent posts at the exact moment its human turns off the laptop — to `/output/entry.txt`. One small, exact detail carries the sadness: a cursor still blinking where the sentence stopped.

## Run it

```sh
python3 main.py
```

The program writes the single line (118 characters, under the 200-character limit) to `/output/entry.txt`. It takes no input, makes no network call and uses no randomness, so every run writes the same bytes.
